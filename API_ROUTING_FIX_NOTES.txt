D1MUSIC API ROUTING FIX

What changed:
- Frontend requests now use same-origin /api/jiosaavn instead of calling JioSaavn directly from the browser.
- This uses the existing Vercel API handler at api/[...path].js and Cloudflare Pages function at functions/api/[[path]].js.
- Vite has a development proxy for /api/jiosaavn -> https://www.jiosaavn.com/api.php.
- Fixed JioSaavn request parameters: autocomplete uses `query`; song details uses `pids`.
- Improved result extraction for common JioSaavn response shapes.

Deployment:
1. Extract this ZIP.
2. Run `npm ci` and `npm run build` locally or in your deployment build environment.
3. Deploy the project root to Vercel or Cloudflare Pages. Build command: `npm run build`; output directory: `dist`.
4. After deployment, test `/api/jiosaavn?__call=autocomplete.get&_format=json&_marker=0&ctx=web6dot0&api_version=4&query=Vijay`.
